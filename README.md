## Featured project

### [FuzzProbe — HTTP Parameter Fuzzer](https://github.com/HUSNAINGHAFFAR878/FuzzProbe)

A command-line Python tool that finds **hidden parameters** in web
applications: it sends one request per wordlist name with a unique marker
value, compares every response against a baseline, and reports the
parameters the server actually recognises — with evidence for each one.
Also includes a GUI version and a web version.
